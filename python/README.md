### Прогнозирование потребления электроэнергии

(Стек: Python · pandas · NumPy · SciPy · statsmodels · Matplotlib · Seaborn)

**Описание проекта**

Практический проект по анализу временных рядов на реальных данных.

Цель проекта — построить модель прогнозирования потребления электроэнергии юридическими лицами для последующего использования прогноза при формировании бизнес-плана на следующий год.

В рамках проекта данные проходят полный аналитический цикл:

EDA → статистический анализ → исследование взаимосвязей → декомпозиция → проверка стационарности → построение моделей → диагностика → валидация → финальный прогноз.

Что исследуется
динамика потребления электроэнергии;
тренд и сезонность;
выбросы и аномальные значения;
статистические зависимости между показателями;
стационарность временного ряда;
качество и устойчивость моделей прогнозирования.
Модели

Для сравнения используются:

экспоненциальное сглаживание;
Holt;
Holt-Winters;
ARIMA;
SARIMA;
Prophet.

Модели сравниваются по качеству прогноза и результатам диагностики остатков.

Результат

На выходе формируется финальный прогноз потребления электроэнергии на будущий период с доверительными интервалами, который может использоваться как исходный показатель для планирования потребления и подготовки бизнес-плана.
