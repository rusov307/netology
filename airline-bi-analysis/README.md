В папке sql предоставлены скрипты для создания отдельных представлений, в последствии используемых в Power BI.

В папке Power BI предоставлен итоговый отчет и рекомендации для бизнеса.

Бизнес-кейс авиапарка.

•	насколько эффективно используется авиапарк; 
•	какие маршруты и аэропорты работают лучше/хуже; 
•	где возникают задержки; 
•	какая загрузка рейсов; 
•	какие направления приносят больше выручки; 
•	как меняется спрос; 
•	насколько заранее пассажиры бронируют билеты; 
•	какая доля поездок требует пересадок; 
•	какие тарифные классы пользуются наибольшим спросом. 

Бизнес-задача.

Необходимо разработать в Power BI интерактивный аналитический дашборд, который позволит руководству:
оценивать спрос, выручку, загрузку рейсов, пунктуальность и эффективность маршрутной сети и находить проблемные направления.
