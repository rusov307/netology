# Аналитика авиапарка — Power BI Dashboard

Интерактивный аналитический дашборд для оценки эффективности использования авиапарка, маршрутной сети и спроса на авиаперевозки.

---

## 📁 Структура репозитория

```
.
├── sql/                  # SQL-скрипты для создания представлений (views)
└── Power BI/             # Итоговый отчёт и рекомендации для бизнеса
```

### 📂 `sql/`

В папке `sql/` предоставлены скрипты для создания отдельных представлений (views), в дальнейшем используемых в Power BI в качестве источников данных.

### 📂 `Power BI/`

В папке `Power BI/` предоставлен итоговый интерактивный отчёт и сформированные на его основе рекомендации для бизнеса.

---

## 🎯 Бизнес-задача

Необходимо разработать в Power BI интерактивный аналитический дашборд, который позволит руководству:

- 📊 оценивать спрос, выручку и загрузку рейсов;
- 🕐 анализировать пунктуальность и эффективность маршрутной сети;
- 🚨 находить проблемные направления.

---

## 📋 Бизнес-кейс авиапарка

Дашборд отвечает на следующие ключевые вопросы:

| # | Вопрос | 
|---|--------|
| 1 | Насколько эффективно используется авиапарк? 
| 2 | Какие маршруты и аэропорты работают лучше / хуже? 
| 3 | Где возникают задержки? 
| 4 | Какая загрузка рейсов? 
| 5 | Какие направления приносят больше выручки?
| 6 | Как меняется спрос? 
| 7 | Насколько заранее пассажиры бронируют билеты?
| 8 | Какая доля поездок требует пересадок? 
| 9 | Какие тарифные классы пользуются наибольшим спросом?

---

## 🛠️ Технологии

- **SQL** — подготовка представлений для источников данных
- **Power BI** — визуализация, интерактивная аналитика, DAX-меры

---

## 📌 Как использовать

1. Выполните SQL-скрипты из папки `sql/` для создания представлений в базе данных.
2. Откройте файл отчёта из папки `Power BI/` в Power BI Desktop.
3. При необходимости обновите источники данных, указав параметры подключения к вашей базе.

---

> 💡 *Все выводы и рекомендации сформированы на основе данных дашборда и предназначены для принятия управленческих решений руководством авиакомпании.*
